# Tips-for-Downloading-Applications-Safely
Our README.md driven project is focused on giving people tips for downloading applications safely. We chose this project because, we have observed that a lot of people are surprisingly horrendous at installing applications safely on their gadgets. 
# Official Websites For Popular Applications
Our README.md can show you official websites for popular applications such as the Apple store as a platform app so as the Google Play Store and web browsers such as Google Chrome, Mozilla Firefox and Brave browsers.
